        Before you start
        
      
        This online version compiles your LaTeX with a free online service. It works well for small and medium documents.
        
      
        
        
        Compiling large documents? Install TeX locally first.
        
        
          
          
        • Large projects (many pages, big images, heavy TikZ, long bibliographies) can be slow, exceed the upload limit (about 4.5 MB), or time out.
          • 
          
        • The free compile service is sometimes unavailable.
          • 
          
        • Your files are sent to a third-party service to be compiled.
          • 
        
        
        
        For large or private documents, run this app on your own computer with TeX installed. It's free, fast and has no size limits.
        
      
        

      
        
        
        1. Install TeX
        
        
        
          
          
          
        
        
        
        
          
        brew install --cask mactex-no-gui
        
          
        Needs Homebrew. Or download the installer from tug.org/mactex.
        
        
        
        
        
          
        winget install MiKTeX.MiKTeX
        
          
        Run in PowerShell. Or download the installer from miktex.org/download.
        
        
        
        
        
          
        sudo apt install texlive-latex-extra texlive-bibtex-extra texlive-publishers biber
        
          
        For Ubuntu / Debian. On Fedora: sudo dnf install texlive-scheme-medium biber
        
        
        

        
        2. Run this app on your computer
        
        
        git clone https://github.com/PriscillajospinG/tex-compiler.git
cd tex-compiler
npm start
        
        
        Needs Node.js 18+. Then open http://localhost:3000.
